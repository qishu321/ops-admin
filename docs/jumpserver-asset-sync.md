# 统一资产同步（JumpServer / 阿里云 / 腾讯云）

入口：资产管理 → 服务器管理 → 资产同步（`/assets/server/sync`）。主机管理的“新增”下拉菜单也提供入口。

## JumpServer 使用步骤

1. 在 JumpServer 创建可读取目标组织下主机、节点的 Access Key。确认后端服务器可以访问 JumpServer，HTTPS 证书应被后端系统信任。
2. 在本平台“凭据管理”新增 **JumpServer API Key**，填写 Key ID 和 Key Secret。主机登录密码或 SSH 私钥分别创建为普通登录凭据。
3. 新增同步源，填写地址、组织 UUID、API 凭据和可选的默认主机登录凭据。默认组织 UUID 为 `00000000-0000-0000-0000-000000000002`。不同组织分别建立同步源。
4. 测试连接，进入“分组与凭据”选择同步范围、目标根组，并按需配置节点映射和节点登录凭据。保存规则。
5. 生成预览，检查新增、更新、无变化、冲突、跳过和本次未发现的资产。地址冲突时搜索并明确关联已有主机，不选择则跳过。
6. 确认同步。任务在后端异步执行，可以在同步记录中查看结果。主机管理会显示 JumpServer 来源或“源端未发现”标记。

资产预览只展示待处理变更：已经同步且无变化的主机不再列出，同步成功的行也会从工作预览中移除。有更新、冲突或未发现等情况时仍会显示。完整资产快照可从“同步记录 → 查看”进入，退出记录详情后恢复待同步视图。节点名称或层级变化会被识别为更新，避免因主机本身无变化而遗漏分组同步。

当前为手动触发同步，未提供定时调度。当前导入具有 SSH 协议的主机；没有 SSH 协议的主机会在预览中说明并跳过。同步入库与 SSH 采集分开记录；可开启同步后自动检测并采集。

## 云主机使用步骤

1. 在「云账号管理」维护阿里云或腾讯云账号、可读实例的 API 权限和可用地域。API 密钥仍由云账号管理保存，资产同步页面不传回密钥。
2. 在「凭据管理」维护主机的 SSH 密码或私钥。云 API 凭据与 SSH 登录凭据分别使用。
3. 在「资产同步」新增阿里云或腾讯云同步源，选择云账号、地域、目标根主机组、环境、默认 SSH 凭据、直连或网关。云账号表格的「同步资产」也可直接带入账号。
4. 新建云同步源默认开启「同步后自动检测并采集」。配置只需保存一次；以后选择该源生成预览、确认同步即可。
5. 默认创建 `阿里云/腾讯云 · 同步源名称 / 地域` 主机组，也可在「分组与凭据」中映射到已有组、设置地域凭据。
6. 预览只展示新增、更新、冲突等待处理项。实例身份按源账号、地域、实例 ID 关联；旧云同步已导入的相同实例会复用，不重复建主机。IP 与本地主机重合但云身份未知时需手工确认关联。
7. 确认后先以事务完成资产入库，再为新增和更新的主机自动检测 SSH、采集信息。无需返回主机表格勾选采集；主机表格保留「采集信息」用于手工刷新。

云平台读取完整分页和配置地域；任一地域失败、不完整分页或重复实例会中止预览，避免把部分结果误认为完整清单。腾讯云内存按 API 的 GiB 单位显示。

已有主机保留 SSH 端口、自定义 SSH 地址、凭据、网关和环境。使用旧内网/公网地址的 SSH 地址会随云端 IP 变化；自定义地址保持不变。已同步且无变化的实例不会覆盖最后一次 SSH 采集的数据。缩小地域范围不会把移出范围的主机标记为删除。

## 自动采集与重试

- 「资产入库完成」与「主机信息采集」分开展示：入库成功不等于认证成功。判断采集结果同时检查连接与 SSH 认证状态，不以接口未报错当作成功。
- 自动采集最多并发 4 台，复用现有单主机 10 秒采集期限；整批任务最多 30 分钟，执行期间持续刷新五分钟租约。
- 认证失败、网络不可达、凭据缺失、停用主机分别报告失败或跳过。失败不回滚已导入的主机、分组及归属。
- 待处理视图保留采集失败、等待采集或未采集的行。点击「重试未成功采集」只处理未成功项，不重复入库，不重复采集成功项。完整快照仍可在同步记录中查看。
- 服务重启或租约过期时，已入库的采集任务标记部分完成，之后可以直接重试。重复点击通过任务状态与采集轮次条件更新防止重复启动或旧任务覆盖新结果。
- 云 API 必须由后端服务器访问；SSH 与网关也由后端连接。尚未使用用户的真实云账号和生产主机联调。

## 分组与凭据规则

- 默认生成 `JumpServer · 同步源名称 / 远端节点层级`，也可把指定节点映射到现有组。多节点资产只创建一台主机，关联多个组。
- 使用同步源 ID、组织配置及远端资产 UUID 维持关联，不按 IP 或名称维持远端身份。已导入资产的同步源不能直接更换组织或地址；需要创建新源并人工处理关联。
- 节点改名、移动会更新自动创建的组；映射到已有的组不会被改名或移动。远端被删除的组默认保留。
- 仅移除该同步源创建并记录的旧归属。已存在的手工组归属不会因映射重叠而变成同步所有。
- 已有主机已绑定的凭据和 SSH 用户保持不变。未绑定凭据时，使用最深节点的凭据，再继承父节点或源默认凭据。同一最深层存在不同凭据时标记冲突，需要修改规则。
- 主机可以在未绑定登录凭据的情况下导入；后续在主机管理中配置。API Key 不能用于 SSH。
- 源端未发现的已关联主机只标记，不删除、不停止本地运维能力。它可能来自删除、移动或 API 权限变化，需要人工核实。缩小同步范围不会将范围之外的主机标记为缺失。
- 同步更新主机名、SSH 地址、端口和启用状态，保留本地云账号关联、网关、环境和手工分组。已有内网地址等于旧 SSH 地址时随之更新，否则保留独立配置。
- 同一本地主机在每个同步源中只能关联一条外部身份；可同时关联 JumpServer 和云平台来源。已有云资产可以通过冲突关联复用，保留其云来源。

## 执行与失败处理

- API 使用 HMAC-SHA256 HTTP Signature，携带 `X-JMS-ORG`。读取 `/api/v1/assets/nodes/` 与 `/api/v1/assets/hosts/`，分页支持标准 `count/results/next` 和数组响应。分页不跟随远端 URL，拒绝 HTTP 重定向，避免携带 API Key 到其他地址。
- 接口字段按 JumpServer v4 的资产、节点结构对接：节点 `id/key/name/value/full_value`，主机 `id/name/address/nodes/protocols/is_active`。节点引用支持 UUID 字符串及 `id/pk` 对象。尚未在用户的真实 JumpServer 版本上联调。
- 任一页失败、不完整节点树、无效数据均中止预览，不导入部分结果。网络读取和本地入库阶段各有两分钟总期限，单个 API 请求超时 15 秒。
- 预览有效期 30 分钟；修改配置后必须重新预览。同一源只允许一个任务；确认预览使用条件更新，重复确认不会重复启动。
- 本地入库在数据库事务内执行，并用数据库互斥行串行处理同步写入，失败回滚。服务重启或任务超时后，五分钟租约到期会将未完成预览/入库任务标记失败并释放源；已入库的采集任务标记部分完成并允许重试。
- 删除同步源会删除配置、映射及其同步记录；导入的主机、组和归属保留为本地资产。列表展示最近 50 条记录。

## 部署与验证

需要同时部署前后端并重启后端。启动时 AutoMigrate 会添加同步源、节点映射、主机映射、任务及同步互斥表，以及主机来源、云同步配置和采集统计字段；主机映射唯一约束会升级为同一同步源内唯一，允许多来源引用同一主机。

单元测试：在 `backend` 下运行 `go test ./...`。新增测试覆盖签名、组织隔离、分页失败、重定向拒绝、取消、节点范围、凭据继承、多组归属、手工组保留和 API/SSH 凭据隔离。界面可使用本地 `.tmp/sync-preview.cjs` 示例服务器验证，示例服务器不访问真实 JumpServer、不修改业务数据库。

接口参考：[JumpServer 官方 API 调用指南](https://www.jumpserver.com/blog/jumpserver-api-interface-calls-guide)、[v4.10 节点序列化定义](https://github.com/jumpserver/jumpserver/blob/v4.10.0/apps/assets/serializers/node.py)、[v4.10 资产序列化定义](https://github.com/jumpserver/jumpserver/blob/v4.10.0/apps/assets/serializers/asset/common.py)。

云同步回归测试还覆盖多地域分页、分页中断与重复数据、容量单位、实例身份隔离、已有连接配置保护、采集并发上限、探测异常和仅重试失败项。界面联调示例 `.tmp/cloud-sync-preview.cjs` 仅使用本地模拟数据，不访问云平台或 SSH。
