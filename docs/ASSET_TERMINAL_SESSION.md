# SSH Web 终端会话保持

2026-10-26：`/assets/terminal` 改为60分钟无真实输入、输出才因空闲断开。

## 行为

- 建立终端后开始计时；用户输入字节或主机输出字节都会重新计时60分钟。
- 心跳不写入Shell，也不显示到终端，不计入用户活动。
- 后端每25秒发送WebSocket Ping和SSH `keepalive@openssh.com` 请求，浏览器原生响应Pong。
- 连续60分钟没有真实输入或输出时，发送WebSocket关闭码4001，释放该连接拥有的SSH客户端；前端显示明确的空闲断开提示。
- 普通页面切换使用KeepAlive缓存，终端标签排除自动十标签淘汰。手动关闭终端标签、关闭会话、退出登录或刷新浏览器仍会释放连接。
- 网络已断、浏览器不回应Pong（90秒）、SSH不回应保活（10秒）、远程Shell自行退出会结束连接；这类故障不显示为“60分钟空闲”。不能靠应用心跳阻止远程主机自己的TMOUT等策略。

## 实现

- `backend/controller/asset_terminal.go`：活动计时、独立空闲定时器、WebSocket/SSH心跳及停止清理。真实活动时间使用带单调时钟的time.Time；到期判定与活动更新加锁，关闭后的活动不能恢复过期会话。
- `backend/controller/controller.go`：接入终端输入、输出观察器；连接结束取消维护协程，原有SSH/WS释放逻辑保留。
- `web/src/views/assets/Terminal.vue`：区分4001空闲关闭与普通网络断开。
- `web/src/layouts/MainLayout.vue`：自动淘汰标签时保留终端，手动关闭流程不变。

## 2026-10-26：活跃会话在一小时附近断开的排查

用户反馈持续使用时也在60分钟附近断开，随后确认是整个页面跳回登录页。故障范围已收敛到登录会话退出导致终端卸载；终端自己的4001空闲关闭不会跳转登录页。没有取得该次续期响应或日志，暂不能区分下述哪种失败触发了退出。

- 已确认并修复一条误关闭路径：访问令牌有效期60分钟，前端提前5分钟开始续期。旧版 `web/src/api/http.js` 在后台续期请求超时、断网或返回503时直接执行退出登录；退出会卸载布局和终端，从而关闭仍有输入、输出的SSH会话。这条路径与终端空闲计时独立。
- 修复后，临时续期失败保留登录状态及现有终端，在下一次后台检查或API请求时重试。续期未成功的API请求仍然失败，不发送未授权请求；续期接口明确返回401、既有6小时登录空闲限制和7天固定期限仍然生效。
- 补修服务端同类误判：`RefreshSession` 原来把会话/账号查询的数据库故障转成认证错误，控制器把所有续期错误都返回401并删除Cookie。现在用 `ErrRefreshSessionRejected` 标记缺失、过期、撤销、账号停用等确定失效；仅此类错误返回401并清Cookie。数据库查询/更新等临时故障返回503并保留Cookie，方便恢复后重试，不返回内部错误详情。
- `web/tests/auth-refresh-session.test.mjs` 使用原始HTTP模块和可控时钟、请求结果，覆盖续期超时/503、跨过原始60分钟令牌期限后恢复、API的401与续期临时失败组合、明确拒绝续期时退出。修改前4项断言失败，修改后4项通过。
- `backend/controller/asset_terminal_test.go` 新增真实WebSocket输入、输出两种独立场景，持续I/O跨过原空闲期限的3倍以上，然后停止I/O，确认最终按最后活动时间空闲关闭。两种场景修改生产代码前均通过，因此没有为这一假设改写后端计时器。测试使用缩短时长，没有进行实等60分钟的在线观测。
- 全前端回归178通过、0失败、2项既有跳过；`npm run build`、`go test ./...`、`go vet ./...`、`go build ./...`均通过。前端构建仍有既有的VueUse注释和大chunk警告。
- 服务端新增回归覆盖会话查询、账号查询和活动更新时间写入失败；前两种故障在修复前可重复失败。另覆盖已建立超过一小时但仍活跃的会话续期、固定到期时间不延长，以及过期、撤销、空闲超时、未知会话、账号停用/删除的拒绝；控制器验证503保留Cookie、401删除Cookie。

当前已修复两条可复现且与该现象一致的登录续期误退出路径。该次请求的具体失败原因没有现场日志，不能据此声称已经回溯出唯一触发原因；也没有实等一小时在线观测。

## 同一主机开启多个独立会话

- 重复点击左侧主机，为该主机创建新的独立终端。标签栏原“新建会话”按钮已按后续需求替换为“发送命令到所有会话”。
- 标签优先显示主机名称，并追加编号，例如 `hh-jp-gm -1`、`hh-jp-gm -2`；未填写名称时显示IP，例如 `192.168.171.57 -1`。每台主机分别计数，关闭标签不重新编号、不复用旧编号。
- 前端会话ID与主机ID分离。每个会话独立持有xterm、WebSocket、输入缓冲、输出解析和当前目录；后端原本每次连接就独立创建SSH客户端与Shell，无需新增接口。
- 切换、清屏、重连、断开、关闭仅作用于选定会话；“关闭其他会话”仍按会话执行。关闭页面标签或卸载页面仍释放全部连接。
- 文件上传/下载绑定发起会话；上传完成后回写原会话，已关闭的会话不会接收回写；下载目录列表的迟到响应不能覆盖另一会话的文件窗口。
- Vue实际挂载测试覆盖三次快速新建、输入/输出/目录隔离、清屏、单个重连/关闭、单独编号和不复用、上传回写隔离、异步目录响应隔离。新增多会话核心用例在修改前失败，修改后通过。
