# 命令过滤

服务器管理 → 命令过滤，仅平台管理员可见、维护。该入口不注册可分配的菜单权限，也不提供资源授权或权限模板项。后端接口按平台管理员身份校验，普通账号即使具有同名功能权限也不能读取或修改配置。

每条规则包含名称、关键词/Go 正则、适用范围、状态和说明。关键词模式支持每行一个关键词，或使用英文逗号、中文逗号、顿号分隔；任意一个命中即拦截，忽略大小写与连续空白，空项忽略。正则表达式始终整体匹配，不拆分。新规则默认停用，启用后才参与拦截。终端与作业都选为全局；终端仅指 SSH，Pod 终端不接入。已打开的 SSH 会话在下次提交时读取最新启用规则。

作业包括快速命令、快速脚本、作业编排与定时任务内的脚本。匹配命令/脚本正文及传入参数和变量值，执行前再次检查。命中规则直接拒绝，风险确认不能绕过。未命中过滤规则时，原有快速命令和脚本的高危、生产环境二次确认继续保留；本次未给定时任务或终端新增确认流程。

SSH 在输入提交符前检查，命中后发送中断取消当前输入，提示命中的规则并保留连接。支持分段输入、常见光标编辑和多行粘贴。历史记录、方向键、Tab 补全和编辑操作正常透传，不会因为这些操作自动拒绝提交。对常见 Shell 提示符，通过 SSH 原始回显还原方向键调出或补全后的命令，提交前按启用规则检查。方向键和回车在同一输入帧中时，先发送方向键并等待回显，再检查回车；不持久化回显内容。特殊自定义提示符、全屏应用及远端脚本内部执行仍不等同于主机级命令审计或隔离。

此功能按提交文本匹配，不是主机内的执行隔离；不展开远端 alias、外部脚本文件、解释器内部计算或已运行程序的行为。资源授权仍遵循已授予主机操作权限即信任的约定。

升级需一起更新前后端，重启后端通过 AutoMigrate 创建 `asset_command_filter` 表。不会自动启用或生成拦截规则。
