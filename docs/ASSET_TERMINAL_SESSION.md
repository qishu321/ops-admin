# SSH Web 终端会话保持

2026-10-26：`/assets/terminal` 改为60分钟无真实输入、输出才因空闲断开。

## 行为

- 建立终端后开始计时；用户输入字节或主机输出字节都会重新计时60分钟。
- 心跳不写入Shell，也不显示到终端，不计入用户活动。
- 后端每25秒发送WebSocket Ping和SSH `keepalive@openssh.com` 请求，浏览器原生响应Pong。
- 连续60分钟没有真实输入或输出时，发送WebSocket关闭码4001，释放该连接拥有的SSH客户端；前端显示明确的空闲断开提示。
- 普通页面切换使用KeepAlive缓存，终端标签排除自动十标签淘汰。手动关闭终端标签、关闭会话、退出登录或刷新浏览器仍会释放连接。
- 网络已断、浏览器不回应Pong（90秒）、SSH不回应保活（10秒）、远程Shell自行退出会结束连接；这类故障不显示为“60分钟空闲”。不能靠应用心跳阻止远程主机自己的TMOUT等策略。

## 实现

- `backend/controller/asset_terminal.go`：活动计时、独立空闲定时器、WebSocket/SSH心跳及停止清理。真实活动时间使用带单调时钟的time.Time；到期判定与活动更新加锁，关闭后的活动不能恢复过期会话。
- `backend/controller/controller.go`：接入终端输入、输出观察器；连接结束取消维护协程，原有SSH/WS释放逻辑保留。
- `web/src/views/assets/Terminal.vue`：区分4001空闲关闭与普通网络断开。
- `web/src/layouts/MainLayout.vue`：自动淘汰标签时保留终端，手动关闭流程不变。

## 验证

- 终端前端7项测试：Vue KeepAlive实际挂载切换、显式关闭清理、标签超额保留、断开原因区分、原有UTF-8与重连隔离。
- 终端后端6项测试：60分钟边界、真实活动重置、空消息无效、心跳不延长空闲、SSH保活阻塞释放、无Pong清理、原有字节输出。使用边界时钟与缩短测试时长的真实WebSocket连接，未宣称进行了实等60分钟的在线观测。
- 全前端回归：174通过、0失败、2跳过（既有告警规则JSON缺失）。
- `npm run build`通过，保留既有VueUse PURE注释和大chunk警告。
- `go test ./...`、`go vet ./...`、`go build ./...`通过。

后端更新并重启后，新建立的终端连接启用该策略；旧进程中的已有连接无法热更新。本轮未重启运行中的服务，避免主动断开用户现有SSH会话。没有修改远程主机的sshd或Shell超时策略。
